# SuperMart Estoque (HTML + CSS + JavaScript)

Como usar: abra o arquivo `index.html` no navegador. Não precisa instalar nada nem ter servidor.

- index.html      estrutura da página (menu lateral + área de conteúdo)
- css/estilo.css  identidade visual do estudo de caso (paleta, Poppins/Inter)
- js/app.js       classes Produto, RepositorioProdutos (CRUD), Telas e App (rotas)
- img/logo.png    logomarca

Os dados ficam salvos no navegador (localStorage). Para voltar aos 10 produtos de exemplo,
apague os dados do site no navegador.

CRUD: Criar (Novo produto) · Ler (lista e detalhes) · Atualizar (Editar, entrada/saída) · Excluir (com confirmação)
